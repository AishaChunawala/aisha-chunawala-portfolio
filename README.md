This repository houses the source code for my personal developer portfolio, custom-built from the ground up to showcase my work across **Generative AI, Voice Agents, Prompt Engineering, and Student Leadership**.

Designed with a **Single-Page Application (SPA)** pattern, it delivers a zero-latency, mobile-first experience tailored for tech recruiters, engineering leads, and AI collaborators.

## 🛠️ Tech Stack & Engineering Principles

* **Semantic Frontend:** HTML5 with ARIA accessibility compliance for screen-reader optimization.
* **Custom Design System:** Responsive CSS3 utilizing CSS Custom Properties (Design Tokens), Flexbox, and CSS Grid (Zero external CSS frameworks).
* **Interactive Engine:** Lightweight, zero-dependency Vanilla JavaScript (ES6+) leveraging `IntersectionObserver` for scroll-spy navigation and zero-layout-shift tab filtering.
* **Deployment & CI/CD:** GitHub Pages with automated deployment pipeline on `main` branch push.
